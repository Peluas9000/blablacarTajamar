# 🚗 Tajamar Mobility - Plataforma de Movilidad Compartida

Plataforma web/móvil de coche compartido (*carpooling*) diseñada para la comunidad educativa de **Tajamar**. Permite a estudiantes y profesores conectar para compartir viajes diarios recurrentes o desplazamientos a eventos puntuales del centro.

## 🎯 Objetivos Principales

1. **Reducir la huella de carbono** y fomentar la sostenibilidad en los desplazamientos a Tajamar.
2. **Facilitar la asistencia a eventos** organizados por el centro mediante trayectos puntuales.
3. **Optimizar plazas vacías** mediante un sistema eficiente de cola de espera para eventos con alta demanda.
